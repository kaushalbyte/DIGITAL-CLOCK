# Digital Clock ⏰

A sleek and real-time Digital Clock built using HTML, CSS, and JavaScript. This project was built to practice JavaScript's Date object and time-handling functions.

## Features ✨
- Displays real-time hours, minutes, and seconds.
- Automatically updates every second.
- Clean and modern UI.

## Technologies Used 🛠️
- **HTML5:** Structure of the clock.
- **CSS3:** Styling, layout, and appearance.
- **JavaScript (Vanilla):** Handling the `setInterval` function and `Date` object logic.
